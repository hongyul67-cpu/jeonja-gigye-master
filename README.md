# 전자 기계 이론 마스터

교과서 「전자 기계 이론」(김철·강민수·김가연·류양근·장대호)의 Ⅰ~Ⅳ 단원을 배우고 확인하는 단일 HTML 학습도구입니다.

`index.html` 하나로 끝나며, 결과 수집·연출·계급·수업모드는 공용 스크립트를 붙여 씁니다.

## 화면

한 도구 안에서 세 가지 화면 언어를 자리에 맞게 씁니다.

| 화면 | 언어 | 무엇을 하나 |
|---|---|---|
| 껍데기 · 스피드 퀴즈 · 종합 시험 | **제어반** — 어두운 조작반, 램프 진행 표시, 푸시버튼 선택지 | 4지선다 |
| 배우기 · 짝 맞추기 | **제도지** — 모눈 도면, 지시선, 표제란 | 13주제 읽기 / 6세트 매칭 |
| 신호 사슬 | **신호 흐름** — 센서 → 제어 → 구동 → 동작 | 6세트, 이어진 구간에만 신호가 흐름 |

## 담은 내용

- **배우기 13주제** — Ⅰ 전자 기계(2) · Ⅱ 기계 설계(6) · Ⅲ 센서(3) · Ⅳ 액추에이터(2)
- **문항 64개** — Ⅰ 10 · Ⅱ 32 · Ⅲ 13 · Ⅳ 9. 종합 시험은 이 중 20개를 뽑아 보기 순서까지 섞습니다.
- **신호 사슬 6세트** — 자동문, 컨베이어 분류, 온도 조절, 로봇 팔, 유압 프레스, 자동 창문
- **짝 맞추기 6세트** — 커플링, 기어의 축 배치, 감아걸기 전동, 감지 대상과 센서, 기계 운동, 액추에이터

Ⅴ. 제어 장치(릴레이·PLC·마이크로프로세서·네트워크)는 이 도구에 없고, 홈 화면에서 **시퀀스·PLC 마스터**로 보냅니다.

## 원본 자료에서 손본 곳

원자료는 `업무폴더 / 01_수업 / 2025이전_수업 / 전자기계이론` 입니다.

| 무엇 | 어떻게 |
|---|---|
| `전자기계이론.pdf` | 본문 없음(표지·머리말·차례 5쪽). 단원 뼈대를 잡는 데만 씀 |
| 03차시 「기계와 기구」 | 파일 내용이 04차시와 완전히 동일. 교과서 42쪽 차례에 맞춰 새로 씀 |
| 12차시 「공·유압 액추에이터」 | 제목만 있고 내용이 비어 있음. 공압·유압 일반 내용으로 채움 |
| 학습지 머리말의 학과·학년 | 넣지 않음. 어느 과에서나 그대로 씁니다 |

배우기 화면에서 위 두 곳은 **확인해 주세요** 상자로 표시해 두었습니다. 원본이 나오면 그것으로 바꾸면 됩니다.
기어 크기별 분류의 수치 구간도 교과서 64쪽 표 확인이 필요해, 배우기에만 두고 시험 문항으로는 쓰지 않았습니다.

## 결과 수집

선생님용 링크(`?rc=...`)로 열면 제출 버튼이 살아납니다. 제출되는 파트는 셋입니다.

- `전자 기계 — 종합 시험`
- `전자 기계 — 신호 사슬`
- `전자 기계 — 짝 맞추기`

평가 판정은 `rubric.json` 이 맡습니다. 스피드 퀴즈는 연습이라 제출하지 않고 랭크 포인트만 쌓습니다.
